УП.03 · Конференция 3.0.0 · Полный локальный комплект

1. ЗАПУСК ПРИЛОЖЕНИЯ

Распакуйте весь архив. Откройте терминал в папке conference-up03.
Для Windows нужен Python 3.12, добавленный в PATH:

  scripts\setup.bat
  scripts\run.bat

На Linux/macOS: make setup, затем make run.
Откройте http://127.0.0.1:8000.
Демонстрационный вход: admin / DemoAdmin!2026.
Другие роли и подробности: conference-up03/README.md.
Остановка сервера: Ctrl+C. Данные сохраняются между запусками.

2. ЧТО ПОКАЗАТЬ ПРЕПОДАВАТЕЛЮ

Порядок демонстрации: conference-up03/DEMO_GUIDE.md.
В папке conference-up03/submission находятся 8 заполненных Word-документов,
распределённых по шести этапам. Впишите свои ФИО и группу.
Карта требований: conference-up03/docs/REQUIREMENTS_MATRIX.md.
Скриншоты и фактические журналы: conference-up03/evidence.

3. ПУБЛИКАЦИЯ В GITHUB

Пошаговые команды: conference-up03/docs/SUBMISSION_GUIDE.md.
conference-history.bundle сохраняет исходный проект УП.02, ветку main,
ветку support/conference-up03 и отдельные коммиты доработок.
Пустой репозиторий создайте в своём аккаунте, затем перенесите историю
по инструкции. Готовые тексты Issue и Pull Request находятся в docs.
Заполните repo_link.txt и ссылки в папках этапов реальным адресом.

5. СОСТАВ КОМПЛЕКТА

conference-up03/               — проект, документы, тесты и доказательства.

conference-history.bundle     — переносимая история Git.

Папка original-data-private предназначена для личного хранения исходных
данных. Не загружайте её в публичный GitHub. Новый проект по умолчанию
использует отдельную базу с вымышленными демонстрационными записями.
