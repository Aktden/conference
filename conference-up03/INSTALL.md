# Установка и конфигурация

## Требования и запуск

Python 3.12, современный браузер, около 250 МБ для среды Python плюс данные. Проверено в Linux x86_64 с Python 3.12.14. BAT подготовлены для Windows 10/11; физический запуск на Windows в этой проверке не выполнялся.

Windows: распакуйте файлы из архиватора, откройте PowerShell в папке проекта, выполните scripts\setup.bat и scripts\run.bat. Setup использует py -3.12, а при отсутствии launcher — python. Активация venv не нужна: скрипты вызывают её интерпретатор напрямую.

Linux/macOS:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
cp .env.example .env
.venv/bin/python main.py
```

Адрес — http://127.0.0.1:8000. Серверный терминал должен оставаться открытым. Остановка Ctrl+C. `uvicorn main:app` также инициализирует БД через lifespan, но `main.py` дополнительно настраивает файл logs/app.log и ротацию.

## Конфигурация

| Переменная | Демо | Назначение |
|---|---|---|
| APP_ENV | demo | production включает строгие требования |
| DEMO_MODE | true | Демо-аккаунты и однократные данные |
| APP_HOST | 127.0.0.1 | Адрес привязки сервера |
| APP_PORT | 8000 | HTTP-порт |
| DATABASE_PATH | data/conference.db | Путь относительно проекта или абсолютный |
| ALLOWED_HOSTS | localhost,127.0.0.1 | Разрешённые Host |
| COOKIE_SECURE | false | В production true и HTTPS |
| ADMIN_PASSWORD | пусто | Уникальный пароль от 14 символов для новой рабочей базы |

## Типовые ошибки

| Симптом | Действие |
|---|---|
| Python не найден | Проверить py -3.12 --version, PATH и установленную версию |
| Библиотеки не установлены | Повторить setup и проверить доступ к PyPI |
| Порт занят | Освободить 8000 или изменить APP_PORT и адрес браузера |
| 401 | Войти снова; сессия действует 8 часов |
| 403 | Проверить роль и обновить страницу для CSRF |
| 409 | Дубликат email/регистрации либо секция заполнена |
| 422 | Исправить перечисленные поля; изменения не записаны |
| Production не запускается | Новая БД, DEMO_MODE=false, COOKIE_SECURE=true и уникальный пароль |

## Перенос исходной базы

Копия исходных данных УП.02 сохранена отдельно от публикуемого проекта. Сделайте рабочую копию conference.db, задайте её путь в DATABASE_PATH и запустите локальный режим. Служебные таблицы добавятся; существующие записи сохранятся, демонстрационное наполнение не смешивается с непустой базой. Проверьте статистику и экспорт. Совместимость старой таблицы participants проверяется тестом test_legacy_database_compatible. Не переносите старые реальные данные в публичный Git.
