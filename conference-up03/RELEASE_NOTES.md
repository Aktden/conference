# Релиз Конференция 3.0.0

Обновление сохраняет предметную область исходной программы и добавляет понятный интерфейс, роли, обработку ошибок, воспроизводимые проверки и резервирование.

Для запуска нужны Python 3.12 и браузер. Выполните scripts/setup.bat и scripts/run.bat, откройте http://127.0.0.1:8000. Демо: admin / DemoAdmin!2026. Сценарий — DEMO_GUIDE.md.

Исправлены запуск на чистой базе, гонка вместимости, межпоточная ошибка SQLite, регистр email, повреждающий импорт и преждевременная отметка печати. Перенос копии исходного SQLite описан в INSTALL.md.

В комплекте исходники, Word-отчёты, тесты, снимки работающего приложения и журналы. История — Git bundle. Рабочие .env, базы и сессии исключены из публикуемого проекта.

Публичный сервер не создавался. Docker и Windows проверяются в целевой среде, Actions — после push. Печатные макеты проверены браузером; физическая печать не выполнялась. Оставшиеся действия — docs/RELEASE_CHECKLIST.md.
