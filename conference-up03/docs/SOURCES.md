# Использованные источники

Основные требования — шесть приложенных методических указаний УП.03, этапы 1–6. Факты о проекте получены из исходного ZIP, кода, выполненных тестов и журналов.

Технические справочники, проверены 4 ноября 2026 года:

- FastAPI lifespan: https://fastapi.tiangolo.com/advanced/events/
- Python sqlite3 и Connection.backup: https://docs.python.org/3/library/sqlite3.html
- SQLite Backup API: https://www.sqlite.org/backup.html
- GitHub Actions для Python: https://docs.github.com/en/actions/tutorials/build-and-test-code/python
- Playwright Python CI: https://playwright.dev/python/docs/ci

Числа тестов, время запросов и наличие уязвимостей берутся из evidence/logs, а не из внешних справочников. Вымышленные данные демонстрации не описывают реальных участников.
