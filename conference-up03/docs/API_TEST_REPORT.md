# Проверка HTTP API релизной сборки

Запросы выполнены к отдельно распакованному архиву через реальный HTTP-сервер. Вход произведён демо-администратором, для изменений передан CSRF. Пароли и токены в доказательства не включены.

| Метод | Путь | HTTP | Результат |
|---|---|---|---|
| GET | /api/participants | 200 | Успех |
| POST | /api/participants | 201 | Успех |
| POST | /api/participants | 422 | Проверьте заполнение полей: email |
| GET | /api/participants/999999 | 404 | Участник не найден |

Проверки 401, 403, 409, истечения сессии и конфликтов данных дополнительно выполнены автоматическими тестами. Полный прогон — check.txt; точные HTTP-результаты — api-cases.json. Некорректный email не вызывает 500 и не раскрывает traceback.
