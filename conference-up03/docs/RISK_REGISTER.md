# Реестр рисков

| Риск | Вид | Вероятность | Влияние | Мера и остаток |
|---|---|---|---|---|
| Публикация демо-паролей на внешнем адресе | Безопасность | Средняя | Высокое | Loopback по умолчанию; production запрещает demo и требует HTTPS; проверить сервер |
| Утечка персональных данных или backup | Безопасность | Средняя | Высокое | Роли, .gitignore, backup вне Git; копии хранить с ограничением доступа |
| Новая уязвимость зависимости | Безопасность | Средняя | Высокое | Зафиксированы версии, pip-audit; повторять перед публикацией |
| Блокировка нескольких сотрудников за одним IP | Безопасность | Средняя | Среднее | Ограничение входа по IP; для сети NAT нужен более точный limiter |
| Отказ диска или потеря компьютера | Эксплуатация | Низкая | Высокое | Backup и проверенный restore; нужна копия вне устройства |
| Рост нагрузки и блокировки SQLite | Эксплуатация | Средняя | Среднее | WAL, busy_timeout, транзакции; для большого события оценить PostgreSQL |
| Ошибка настройки HTTPS/cookie/hosts | Эксплуатация | Средняя | Высокое | Production guard и инструкция; внешний HTTPS пока не проверен |
| Изменения среды Windows/Docker | Эксплуатация | Средняя | Среднее | CI матрица и контейнерный job; нужен реальный зелёный workflow |
| Переполнение диска логами/backup | Эксплуатация | Средняя | Среднее | Логи ротируются; backup удалять по согласованной политике хранения |
| Ошибка оператора при восстановлении JSON | Эксплуатация | Средняя | Высокое | Явное подтверждение и валидация; заранее сохранить текущий экспорт |

Оценки качественные, не статистическая модель. Принят учебный контекст: один локальный сервер и небольшая база. Производственная эксплуатация требует проверки оставшихся рисков в целевой среде.
