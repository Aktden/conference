## Ошибка SQLite при одновременной регистрации

На версии 280c036 параллельная регистрация двух участников может завершиться sqlite3.ProgrammingError из-за использования соединения в другом рабочем потоке.

### Воспроизведение

1. Установить зависимости Python 3.12.
2. Запустить `python -m pytest tests/test_app.py::test_parallel_capacity -v` на версии до исправления.
3. При параллельном исполнении наблюдать ошибку SQLite вместо управляемого результата. Ошибка зависит от планирования потоков; сохранён фактический упавший прогон.

Ожидается: один участник записан (201), второй получает сообщение о заполненной секции (409). Фактически: ProgrammingError. Окружение: Linux x86_64, Python 3.12.14, FastAPI 0.162.0, Starlette 1.10.0.

Доказательство: evidence/logs/concurrency-before.xml. Причина и решение: docs/INCIDENT_REPORT.md. Исправление: e8a85b7. Регрессионный тест должен оставаться в CI.
