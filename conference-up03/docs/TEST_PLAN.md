# План проверки качества

Объект: Конференция 3.0.0, Python 3.12, FastAPI/SQLite. Цель: проверить функциональность, отказоустойчивость операций и контроль доступа до учебной демонстрации. Тестовая среда использует отдельные временные БД и вымышленные адреса example.com.

| Группа | Проверки | Инструмент | Доказательство |
|---|---|---|---|
| Запуск | Чистая база, однократное наполнение, повторный запуск | pytest, отдельный процесс | check.txt, release-verification.json |
| Авторизация | Вход, выход, срок сессии, Origin, CSRF, блокировка | pytest | tests/test_app.py |
| Роли | viewer не читает именные записи, operator не удаляет/экспортирует | pytest + UI | check.txt, viewer-reports.png |
| Участники | CRUD, email без регистра, кириллица, пустые поля | pytest + UI | duplicate-error.png |
| Секции | Расписание, вместимость, уменьшение лимита, удаление | pytest + UI | sections.png |
| Посещаемость | Запись, дубль, превышение мест, гонка двух запросов | pytest | test_parallel_capacity |
| Бейджи | Одиночная/массовая отметка, макет печати, отмена печати | pytest + UI | badges.png, ui-report.json |
| Экспорт | JSON, CSV BOM, защита формул | pytest + UI | check.txt |
| Импорт | Round-trip, ID, email, ссылки, лимит секции, подтверждение | pytest + UI | check.txt, ui-report.json |
| Резервирование | Backup API, restore в новый файл, очистка сессий | pytest + CLI | backup-restore.json |
| Браузер | 7 страниц, ошибки JS, сеть, мобильная ширина 390 px | Chromium + Playwright | ui-report.json, screenshots |
| Производительность | 100 последовательных запросов к каждому из 3 маршрутов | HTTP timing | performance.json |

Команды: scripts/check.bat или make check; scripts/ui_smoke.py для UI. Критерии: нет упавших тестов, покрытие не ниже 80%, нет ошибок JS/500 в позитивных UI сценариях, отрицательные запросы возвращают контролируемый 4xx, backup восстанавливает число записей.

Физическая печать, Docker, Windows и внешний HTTPS не считаются проверенными данным локальным запуском. Lighthouse не запускался; использованы реальные Navigation Timing и последовательные HTTP-замеры. Масштабируемость и высокая конкуренция не оценивались.
