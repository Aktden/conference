# История изменений

## 3.0.0 — 2026-11-04

### Добавлено

- Единый адаптивный интерфейс, карточки программы, поиск, фильтры и печатные бейджи.
- Роли, серверные сессии, CSRF, ограничения входа и журнал действий.
- JSON/CSV, валидация восстановления, healthcheck, ротация логов.
- API и UI проверки, Backup API SQLite и безопасное восстановление.
- BAT, Makefile, Docker/Compose, CI Linux/Windows и контейнера, релизный ZIP.
- Материалы шести этапов практики и фактические доказательства.

### Исправлено

- Инициализация БД в lifespan, пути относительно проекта.
- Межпоточный сбой SQLite для соединений отдельного запроса.
- Гонка вместимости, регистр email, кириллический поиск.
- Повреждающий импорт и повторное демо-наполнение после намеренной очистки.
- Окно печати больше не означает выдачу бейджа.

### Проверки

Локальные результаты — evidence/logs. GitHub Actions, Docker и Windows подтверждаются отдельно в соответствующей среде.

## 2.0.0 — исходный архив УП.02

FastAPI/SQLite с участниками, секциями, посещаемостью, бейджами и отчётами. Снимок сохранён первым коммитом, назначение программы не менялось.
